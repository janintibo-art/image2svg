Deux façons de convertir

La vectorisation redessine l'image en aplats de couleur, idéale pour les logos. L'encapsulation conserve la photo à l'identique dans le fichier SVG.

Visionneuse intégrée

Ouvrez n'importe quel SVG et zoomez sans perte de netteté, à la molette sur Windows, à deux doigts sur Android.

Rien ne quitte votre appareil

Tout le traitement se fait en local. Aucune image n'est envoyée sur un serveur, aucun compte n'est demandé.

Si Windows bloque le fichier

L'application n'est pas signée par un certificat payant, alors SmartScreen peut afficher un avertissement. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Le code source complet est consultable sur le dépôt.
